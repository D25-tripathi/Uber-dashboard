🚖 Uber Data Analytics Dashboard

📊 Project Overview

This project focuses on analyzing Uber ride data to extract meaningful insights using **Microsoft Excel** and **Power BI**.
The goal of this project is to understand ride patterns, customer demand, revenue trends, and operational efficiency through interactive dashboards.

This project demonstrates practical **data analytics skills** including data cleaning, data modeling, visualization, and business insight generation.

---

## 🎯 Objectives

* Analyze Uber ride data to identify trends and patterns
* Build an interactive dashboard for data visualization
* Provide business insights for better decision making
* Practice real-world data analytics workflow

---

## 🛠 Tools & Technologies Used

* **Microsoft Excel** – Data cleaning and preprocessing
* **Power BI** – Dashboard creation and data visualization
* **Data Analysis** – Trend analysis and KPI tracking

## 📈 Key Dashboard Insights

The dashboard provides insights such as:

* Total number of rides
* Revenue generated from trips
* Ride demand by **time and date**
* Peak hours of Uber usage
* Trip distribution by location
* Customer ride trends

## 📊 Dashboard Features

* Interactive filters
* Dynamic charts and visuals
* KPI indicators
* Time-based ride analysis
* Location-based ride analysis

## 🔍 Data Analysis Process

1. **Data Collection**

   * Uber trip dataset stored in Excel

2. **Data Cleaning**

   * Removing duplicates
   * Handling missing values
   * Formatting date and time fields

3. **Data Modeling**

   * Preparing structured data for Power BI

4. **Visualization**

   * Creating charts, graphs, and KPIs
   * Designing an interactive dashboard
